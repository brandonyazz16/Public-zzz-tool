Remielle .zon

Turns a build into the Remielle server’s player file (.zon). Import your file to equip the build on that character and download the edited file, or copy just the character block and paste it in yourself.

Server commands

1. Get your .zon — run in your Remielle folder. This turns your saved player into a .zon file you can import here:

remielle print-player remielle-storage/players/1.bin

2. Put it back in the game — run in your Remielle folder. It packs your edited .zon file into the .bin for the game data:

remielle pack-player 1.zon --output=remielle-storage/players/1.bin
Change log

What’s in the file

0 selected
Pick a build and click Equip — each one goes onto its character in the same file, so you can set up several characters and download once. Load into Builder reads a character’s gear from the file into the Builder so you can see the stats and change it. Only those characters change: Mindscape (rank), W-Engine and refine, and disc slots 1–6. Everything else in your file stays the same, including your unequipped W-Engines and discs. Discs have no level in the file (the server sets the values); each substat’s + is its extra rolls (rolls − 1). Empty slots are written as null.

(New) Remielle

This is the installation guide for the new Remielle server emulator.
You're going to run everything in a CMD, unless you want to add it to PATH.

First, you're going to need to go to the files' repositories. There are two options from there.

Remielle: the server emulator.
Thaumiel: the patch.

  1. You can install the pre-built emulator and patch.
  2. You can use Git and Zig 0.17 to build from source.

I personally recommend the second option because it's just easier, IMO, but that's completely up to you.

The next step is to download the client (if you haven't done so already). This is for version 3.4.0 onwards.

Then add Thaumiel and the remielle-bootstrap to the client directory.

Next, move to the Remielle server emulator. It should just be a remielle.exe with no .dll. Run it once, then inside the CMD press Ctrl+C to shut down the server. Once that's done, look for remielle-storage -> players -> 1.bin.

Once there, put this command in a CMD and press Enter: remielle print-player remielle-storage/players/1.bin. This will print (make) a 1.zon. This is how you're going to add discs and whatnot. You can either use the .zon Builder or edit it yourself.

Once it's edited, use this command: remielle pack-player 1.zon --output=remielle-storage/players/1.bin to "pack" (put) the edited file into the 1.bin.

After every edit you will have to re-log, but you never have to close and re-open the game.

If you did this with Git and Zig, all the files will be in zig-out/bin. Then just move the remielle.exe and storage to a different folder in your user directory.

How to edit characters

OK, this is how you edit characters (this is literally all you need to do).

After creating the .zon file, open it in Notepad and look for the character you want.

There are 10 sections you can edit.

The first is the character:

.{
     .name = "Banyue",

Most characters use their first names only, with a few odd exceptions like Ye Shunguang and Soldier 0 - Anby,
but for the most part this doesn't matter to you.

Next is the level and rank (simple answer: rank always stays 6).

.level = 60,

As the name suggests, it changes the level of the character.

.rank = 6,

I have no idea what this does; just keep it at 6 or the commands will get angry.

Next is favorite and unlocked Mindscapes.

.favorite = false,

Pretty simple: true or false.

Unlocked Mindscapes:

.unlocked_mindscape = 0,

0 = M0 and 6 = M6. Pretty simple.

Next is the Mindscape banner, or tab state as it's called.

.mindscape_tab_state = .{
    false, 
    false,
    false,
    false,
    false,
    false,
},

This is the banner section, or tab. M1 changes the first false to true, like so:

.mindscape_tab_state = .{
    true, 
    false,
    false,
    false,
    false,
    false,
},

And so on. Anything above M3 turns the first three back to false and turns the first of the last three to true, like so:

.mindscape_tab_state = .{
    false, 
    false,
    false,
    true,
    false,
    false,
},

The Mindscape unlocks and this work in tandem with each other, so they have to match.

Next is show_weapon_status and weapon.

I don't know what show_weapon_status does, and I don't really care.

weapon is the W-Engine a character has equipped. For example,
Soldier 0 - Anby with her signature:

.weapon = .{ .name = "Severed Innocence", .refine = 1 },

Changing the "refine" just changes the number of copies you have of the W-Engine.

Next is equipment, the most complicated part (if you do this by hand, I pray for you).

The base is this:

.equipment = .{
    .@"1" = null,
    .@"2" = null,
    .@"3" = null,
    .@"4" = null,
    .@"5" = null,
    .@"6" = null,
},

To add a disc, you're going to use this for every disc (I highly recommend you copy this):

.@"1" = .{
    .id = .{ .name = "Bunny in Wonderland [1]", .rarity = .s },
    .main_property = .{ .key = "HP" },
    .sub_properties = .{
        .@"1" = .{ .key = "Percent ATK", .@"+" = 3 },
        .@"2" = .{ .key = "Anomaly Proficiency", .@"+" = 1 },
        .@"3" = .{ .key = "Percent DEF", .@"+" = 1 },
        .@"4" = .{ .key = "PEN", .@"+" = 0 },
   },
},

So you have the slot:

.@"1" = .{},

The name of the disc. Editing rarity is self-explanatory.

.id = .{ .name = "Bunny in Wonderland [1]", .rarity = .s },

Then the main stat:

.main_property = .{ .key = "HP" },

Then the four substats:

.@"1" = .{ .key = "Percent ATK", .@"+" = 3 },
.@"2" = .{ .key = "Anomaly Proficiency", .@"+" = 1 },
.@"3" = .{ .key = "Percent DEF", .@"+" = 1 },
.@"4" = .{ .key = "PEN", .@"+" = 0 },

Editing the substat values works as follows: 0 = base stat value, 1 = +1 to the base value.
As you can see, the game does the calculations by itself.

Update client

To update your client, use zift for ZZZ versions above 3.3.4. For lower versions, use Hpack instead — they do roughly the same thing. Hpack has a (sort of) interactive CMD, while zift is purely command-line. One command is zift [directory], which scans and cleans your directory.

zift <source> <target> [out] creates a delta, and zift <delta> <directory> applies one. Not sure what else either command does beyond that — the “create delta” side of things is honestly beyond my paygrade right now.

To work around this — since I can't get eldreda installed — I just deleted the remielle files (remielle.exe and thaumiel.dll) from the client directory, and the files from where you build the exes, then used git to pull the updated resources for remielle and thaumiel. That worked, but it won't forever: remielle is being discontinued once eldreda reaches feature parity with it. For now, both remielle and eldreda are being updated together.

The update from 3.3.4 to 3.4.1 did go through, though not smoothly — two errors came up that were fixed by reinstalling remielle, same as before. No idea if that fix carries over to eldreda, and honestly I can't test it anyway since I can't install eldreda yet.

Tutorials

Making a disc manually

To make a disc manually, first put zig build ctl -- create-equip [UID]. This command will only work in the remielle directory.

The next part is the disc ID. Use zzz.gachabase.net to get them, or use zzz.nanoka.cc/equipment.

Add it to the previous command like so: zig build ctl -- create-equip [UID] [discID][rarity][slot]

Example: zig build ctl -- create-equip 999 33341. This will give you Dawn's Bloom at S-rank in slot 1.

Next are the sub-stats, so use the exact same command as before: zig build ctl -- create-equip [UID] [discID][rarity][slot] [level] 5 [MainStat] [basestat] 0 [substat] [basestat] [addition]

Base stats are provided up in the automatic builder, and addition means how many rolls it has. If you don't know what I'm talking about, look it up.

Now add 3 more sub-stats like this: zig build ctl -- create-equip [UID] [discID][rarity][slot] [level] 5 [MainStat] [basestat] 0 [substat] [basestat] [addition] [substat] [basestat] [addition] [substat] [basestat] [addition] [substat] [basestat] [addition]

Percentages are written like this: 480 → 4.8% and 240 → 2.4%. Flat values like ATK are just numbers, so 19 is just 19.

So if we go back to the original command: zig build ctl -- create-equip 999 33341 15 5 11103 550 0 21103 480 1 12102 300 5 23203 9 2 11103 112 1

This would give us a Dawn's Bloom at S-rank in slot 1 with an HP main stat, and the sub-stats CDMG, ATK% +4, PEN +1 and HP.

Making character mindscapes

To make character mindscapes you need this command: zig build ctl -- mod-avatar-meta talents [UID]

Then add the character ID: zig build ctl -- mod-avatar-meta talents [UID] [CharacterID]

Use zzz.gachabase.net to get the IDs, or use zzz.nanoka.cc/equipment.

And the mindscapes, where 0 means M0 and 6 means M6: zig build ctl -- mod-avatar-meta talents [UID] [CharacterID] [Mindscape]

For example: zig build ctl -- mod-avatar-meta talents 999 1421 0. This will give Pan at M0.

I don't know how to edit skills.

Making a W-Engine

To make a W-Engine you need this command: zig build ctl -- create-weapon [UID]

Then add the W-Engine ID: zig build ctl -- create-weapon [UID] [WEngineID]

Add the level: zig build ctl -- create-weapon [UID] [WEngineID] [Level]

Then add the rarity: zig build ctl -- create-weapon [UID] [WEngineID] [Level] [rarity]

Then the refinement (basically how many copies): zig build ctl -- create-weapon [UID] [WEngineID] [Level] [rarity] [Refinement]

For example: zig build ctl -- create-weapon 999 14159 60 5 3. This will give you Knight's Extolment (Sigrid's signature) at level 60, S-rank (yes, you can make an S-rank engine A-rank), at W3.

Remember, the base of a W-Engine is 1.

Deadly Assault

To change the first regular Deadly Assault option, you have to do: zig build ctl -- mod-hadal-entrance boss_challenge_trial_1 ID

To change the first hard mode Deadly Assault option, you have to do: zig build ctl -- mod-hadal-entrance boss_challenge_adversity_1 ID
