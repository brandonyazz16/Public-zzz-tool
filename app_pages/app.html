App tools

The app's own tools: they read and write files on your PC, which a web page can't do.

.zon Builder Guides App tools

Check file is locked

Pick your Remielle server's remielle.exe first. Files are checked against the names and data in your own remielle.exe, so the check always matches your server.

Check file

Checks a Remielle player file (.zon) the way Remielle's server does, and fixes what it finds. Fix all never removes anything and never adds new characters — those only happen when you click their own button.

Game save

Reads your save out of the game into Check file, and packs a checked file back in — using Remielle's own print-player and pack-player. The save is only replaced after the new one has been packed and read back, and the old one is always backed up first.

After packing or restoring, log out and back in to the game to see the change (the server can stay open).

Backups

Newest first (times in UTC). Restoring backs up the current save first, so it can be undone too. Backups are never deleted by the app.

Game data

Level-60 base stats read straight from your remielle.exe (the game's own formula: level 1 + growth × 59 levels + rank-6 ascension). Pick remielle.exe in Game save first.

Exe vs site

What your remielle.exe has that the site doesn't, and level-60 numbers that differ from the site's. Nothing is changed — this is a list to check.
